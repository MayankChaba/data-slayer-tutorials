Questions

How is usage billed?

Per result. You pay only for the records a run produces, at each scraper's published rate. There is no seat fee and no monthly minimum.

Do prices differ by platform?

Yes. Each scraper has its own rate because the underlying data and effort differ. The table above shows the entry price per 1,000 results for each platform.

Is there a free way to start?

Apify includes monthly free usage credit on the free plan. It is enough to run several scrapers end-to-end before you commit to a paid plan.

What happens if a run fails?

Failed runs are not billed as results. You can see success rates on every scraper page, measured over the last 30 days.
