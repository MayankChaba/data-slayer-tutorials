Example request

Every X (Twitter) scraper follows the same shape: POST a JSON body to the actor's run endpoint and read typed records back. Here it is in cURL, Node.js and Python.

POST/v2/acts/data-slayer~twitter-user/run-sync-get-dataset-items
request
curl -X POST "https://api.apify.com/v2/acts/data-slayer~twitter-user/run-sync-get-dataset-items" \
  -H "Authorization: Bearer $APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "profiles": [],
    "maxItems": 100
  }'
import { ApifyClient } from 'apify-client';

const client = new ApifyClient({ token: process.env.APIFY_TOKEN });

const run = await client.actor('data-slayer/twitter-user').call({
  "profiles": [],
  "maxItems": 100
});

const { items } = await client.dataset(run.defaultDatasetId).listItems();
console.log(items);
import os
from apify_client import ApifyClient

client = ApifyClient(os.environ["APIFY_TOKEN"])

run = client.actor("data-slayer/twitter-user").call(run_input={
    "profiles": [],
    "maxItems": 100,
})

for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)
