Scraper APIs for public social-media data

dataslayer publishes 102 production scraper APIs for Instagram, LinkedIn, X, Facebook, TikTok, Reddit, Other. They are built and run on Apify, and return clean, structured rows from public data.

What we publish

Every scraper does one job — a profile, a post, a follower list, a search. Each one publishes its inputs, its output fields and its price before you commit, so you always know what a run will return. Results come back as typed JSON, or you can download the dataset as CSV or Excel.

How it works

  1. 01 — Create an Apify account and copy your API token.
  2. 02 — POST a JSON body to the scraper's run endpoint.
  3. 03 — Read typed records back, or export the dataset.

Data & compliance

  • Public data only. The scrapers read publicly accessible information. None of them ask for your login, cookies or a logged-in session.
  • Priced on results. You pay for the records a run returns, at each scraper's published rate. Failed runs are not billed as results.
  • Trademarks. dataslayer is not affiliated with Instagram, LinkedIn, X, Facebook, TikTok or Reddit. Their names and logos belong to their respective owners.
  • Where it runs. Scrapers are published on Apify Store as Data Slayer, so billing, runs and logs all live in your Apify account.
