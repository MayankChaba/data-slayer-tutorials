What you can scrape from LinkedIn

Profiles

Public profile data: headline, experience, education, skills, location, company and follower counts.

Companies

Company pages with industry, size, headquarters, specialties, website and description.

Jobs

Public job postings by keyword, company or location, with title, description and posting metadata.

Posts & engagement

Company and profile posts with reactions, comments, shares and author details.

People & company search

Search public profiles and companies by industry, location, headcount, title and technology filters.

Engagers

Everyone who reacted to or commented on a post, deduplicated into one list.

Example request

Every LinkedIn scraper follows the same shape: POST a JSON body to the actor's run endpoint and read typed records back. Here it is in cURL, Node.js and Python.

POST/v2/acts/data-slayer~linkedin-profile-scraper/run-sync-get-dataset-items
request
curl -X POST "https://api.apify.com/v2/acts/data-slayer~linkedin-profile-scraper/run-sync-get-dataset-items" \
  -H "Authorization: Bearer $APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "linkedin_urls": [
      "https://www.linkedin.com/in/williamhgates"
    ]
  }'
import { ApifyClient } from 'apify-client';

const client = new ApifyClient({ token: process.env.APIFY_TOKEN });

const run = await client.actor('data-slayer/linkedin-profile-scraper').call({
  "linkedin_urls": [
    "https://www.linkedin.com/in/williamhgates"
  ]
});

const { items } = await client.dataset(run.defaultDatasetId).listItems();
console.log(items);
import os
