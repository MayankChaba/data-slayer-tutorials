API documentation

Every dataslayer scraper is a production Apify actor. You call one endpoint, send a JSON body and read typed records back. This page covers the whole loop.

Quickstart

01

Get a token

Create a free Apify account and copy your API token. One token works across every dataslayer scraper.

02

POST your input

Send a JSON body to the actor's run endpoint. Inputs are validated against a published schema before the run starts.

03

Read the dataset

The run writes typed records to a dataset you can fetch as JSON, CSV or Excel — or stream straight into your stack.

Authentication

Pass your token as a token query parameter or an Authorization: Bearer header. Requests without a valid token return 401.

Errors & limits

  • 401 — missing or invalid token.
  • 400 — input failed schema validation; the message names the field.
  • 429 — rate limited; back off and retry.
  • Runs are asynchronous: poll the run status, then fetch the dataset when it succeeds.

import { ApifyClient } from 'apify-client';

const client = new ApifyClient({ token: process.env.APIFY_TOKEN });

const run = await client.actor('data-slayer/instagram-post-details').call({
  "postUrls": [
    "DVEGQskiMcy"
  ],
  "postCode": ""
});

const { items } = await client.dataset(run.defaultDatasetId).listItems();
console.log(items);
import os
from apify_client import ApifyClient

client = ApifyClient(os.environ["APIFY_TOKEN"])

run = client.actor("data-slayer/instagram-post-details").call(run_input={
    "postUrls": [
        "DVEGQskiMcy",
    ],
    "postCode": "",
})

for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)
