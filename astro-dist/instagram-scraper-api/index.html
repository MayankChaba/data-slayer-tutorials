What you can scrape from Instagram

Profiles

Public profile details: bio, follower and following counts, post count, verification, business category and profile picture.

Posts & carousels

A profile's or hashtag's posts with captions, media URLs, likes, comments, timestamps and tagged users.

Reels

A profile's reel feed and reels by audio, with play counts, likes, comments and media URLs.

Comments

Public comments on a post or reel, with author, text, likes and reply threads.

Followers & following

Follower and following lists for a public account, with usernames and profile summaries.

Hashtags & search

Hashtag and keyword search across users, hashtags and places, with ranked results.

Example request

Every Instagram scraper follows the same shape: POST a JSON body to the actor's run endpoint and read typed records back. Here it is in cURL, Node.js and Python.

POST/v2/acts/data-slayer~instagram-post-details/run-sync-get-dataset-items
request
curl -X POST "https://api.apify.com/v2/acts/data-slayer~instagram-post-details/run-sync-get-dataset-items" \
  -H "Authorization: Bearer $APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "postUrls": [
      "DVEGQskiMcy"
    ],
    "postCode": ""
  }'
import { ApifyClient } from 'apify-client';

const client = new ApifyClient({ token: process.env.APIFY_TOKEN });

const run = await client.actor('data-slayer/instagram-post-details').call({
  "postUrls": [
    "DVEGQskiMcy"
  ],
  "postCode": ""
});

const { items } = await client.dataset(run.defaultDatasetId).listItems();
console.log(items);
import os

Frequently asked questions

Do I need an Instagram login to use the API?+

No. Every dataslayer Instagram scraper reads public data only, so there is no login, no session to keep alive and no cookie of yours at risk.

What data can I scrape from Instagram?+

Public profiles, posts and carousels, reels, comments, followers, following, hashtags, mentions and user, hashtag or place search results.

How much does an Instagram scraper API cost?+

You pay per result returned, at each scraper's published rate through your Apify account. There is no subscription or seat fee.

What format does the data come back in?+

Typed JSON records by default. You can also download the run's dataset as CSV or Excel, or stream it into your own stack.
