From input to structured rows in one request

No browser to run, no proxy to rent and no queue to build.

  1. 01

    Pick a scraper

    Each scraper does one job, such as profile details, post comments or follower lists. Its page lists every input it takes and every field it returns.

  2. 02

    Send one request

    Post your input with an Apify API token. You can also start runs from the Apify Console or from n8n, Make and Zapier.

  3. 03

    Read structured rows

    Results come back as JSON, or download the dataset as CSV or Excel. You pay for the results the run returned.

Questions

The short answers. More detail in the docs.

What is dataslayer?+

dataslayer is a catalog of 102 scraper APIs that return structured JSON from public social-media data across Instagram, LinkedIn, X, Facebook, TikTok, Reddit, Other. Each scraper is an Apify actor: send one JSON request and read typed records back, paying per result.

Do I need a login or cookies to use the scrapers?+

No. Every scraper reads public data only, so there is no login, no session to keep alive and no cookie of yours at risk.

How much do the scraper APIs cost?+

You pay per result, at each scraper's published rate, billed through your Apify account. Entry price is from $0.450 per 1,000 results, with no subscription and no seat minimum.

What format does the data come back in?+

Typed JSON records by default. You can also download a run's dataset as CSV or Excel, or stream it into your own stack.

Which platforms are supported?+

Instagram, LinkedIn, X (Twitter), Facebook, TikTok and Reddit, across 102 scrapers in total.

How do I get started?+

Create an Apify account, copy your API token, then POST a JSON body to the scraper's run endpoint. The documentation walks through the whole loop in three steps.
