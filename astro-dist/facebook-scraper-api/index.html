Example request

Every Facebook scraper follows the same shape: POST a JSON body to the actor's run endpoint and read typed records back. Here it is in cURL, Node.js and Python.

POST/v2/acts/data-slayer~facebook-search-pages/run-sync-get-dataset-items
request
curl -X POST "https://api.apify.com/v2/acts/data-slayer~facebook-search-pages/run-sync-get-dataset-items" \
  -H "Authorization: Bearer $APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "query": "new york"
  }'
import { ApifyClient } from 'apify-client';

const client = new ApifyClient({ token: process.env.APIFY_TOKEN });

const run = await client.actor('data-slayer/facebook-search-pages').call({
  "query": "new york"
});

const { items } = await client.dataset(run.defaultDatasetId).listItems();
console.log(items);
import os
from apify_client import ApifyClient

client = ApifyClient(os.environ["APIFY_TOKEN"])

run = client.actor("data-slayer/facebook-search-pages").call(run_input={
    "query": "new york",
})

for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

Yes. The Ads Library scraper returns public ad records for a page, including creative text and run dates.
